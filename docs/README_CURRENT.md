# Zerodha Platform Documentation (Current Canonical Index)

This file is the single source of truth for the current project layout, per-module docs, key commands, and service endpoints. Prefer this over older “fix”/status documents.

---

## Quick start

- Start everything: `docker compose up -d`
- Check containers: `docker ps`
- Health checks (local):
  - Market Data API: http://localhost:8004/health
  - Dashboard backend: http://localhost:8001/health
  - Engine API: http://localhost:8006/health
  - News API: http://localhost:8005/health
  - Market Data Dashboard: http://localhost:8008/api/health
  - Redis WS Gateway: ws://localhost:8889 (health: http://localhost:8889/health)

Ports in use (host):
- 8001 dashboard-backend, 8004 market-data-api, 8005 news-api, 8006 engine-api, 8008 market-data-dashboard, 8888 dashboard-frontend, 8889 redis-ws-gateway, 6380 redis (internal 6379), 27018 mongodb (internal 27017).

## Service entrypoints & commands
- Market Data API (FastAPI): `python -m market_data.api_service`
- Engine API: `python -m engine_module.api_service`
- Redis WS Gateway: `python -m redis_ws_gateway.main`
- Dashboard backend: `uvicorn dashboard.dashboard_pro:app --host 0.0.0.0 --port 8001`
- Dashboard frontend: Vite dev/serve via `dashboard/modular_ui` (see its README)
- Historical replay: `python -m services.historical_data_replay_service`
- Automatic trading runner: `python -m services.automatic_trading_runner`

Unified mode helpers (historical/live):
- Start historical: `python start_unified.py --historical --date YYYY-MM-DD --speed <1|10|100>`
- Start live: `python start_unified.py --live`
- Verify setup: `python verify_unified_mode.py`

## Current data flow (live & historical)
1) Collectors → Redis pub/sub (`raw_ticks:*`, Kite tick schema preserved)
2) OHLC + multi-timeframe aggregators → Redis + Mongo
3) Indicators → Redis (`indicator:*`), surfaced via Market Data API
4) Engine / bots consume indicators & signals → decisions/orders
5) Dashboards read from APIs + Redis WS Gateway

## API surface (high level)
- Market Data API (port 8004)
  - `GET /health`
  - `GET /api/v1/market/ohlc/{instrument}?timeframe=minute&limit=N&order=asc|desc`
  - `GET /api/v1/ohlc/{instrument}` (alias, same params)
  - Indicators: `GET /api/v1/technical/indicators/{instrument}` (query params for timeframe/window)
- Dashboard backend (port 8001): trading/risk/analytics endpoints (see `dashboard/README.md`)
- Engine API (port 8006): strategy/decision endpoints (see `engine_module/README.md`)
- News API (port 8005): news feed endpoints (see `news_module/README.md`)

## Environment & config
- `.env` / `local.env` / `config.local.env` for local overrides
- Docker compose: `docker-compose.yml` (+ `.live`, `.historical`, `.mock*` variants)
- Credentials: `credentials.json` (mounted read-only where needed)
- Mode config: `.mode_config.json` (autogenerated)
- WebSocket tick mode: `KITE_TICKER_MODE=full|quote|ltp`
