💡 HOW TO USE
─────────────────────────────────────────────────────────────────────────────

Setup (First Time):
  1. Ensure API credentials from https://kite.zerodha.com/api
  2. Set environment (optional, but recommended):
     export KITE_API_KEY="your_key"
     export KITE_API_SECRET="your_secret"
  3. Run: python start_unified.py --live
  4. Browser opens automatically if needed
  5. Log in → Credentials saved → Trading ready

Normal Startup (Token Valid):
  $ python start_unified.py --live
  ✅ Token validated successfully
  ✅ Credentials are valid!
  ✅ Live trading ready

After Token Expires (24+ hours):

  ⚠️ Token expired (age: 24h 15m, limit: 23h)
  🌐 Opening browser for re-authentication...
  [User logs in again]
  ✅ New token obtained
  ✅ Live trading ready
